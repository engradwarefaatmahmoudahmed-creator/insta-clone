# Insta Clone 📸

A full-stack Instagram-style social media application built with Django.

## Features

- User Registration
- User Login and Logout
- Custom User Model
- Profile Picture and Bio
- Edit Profile
- Follow and Unfollow Users
- Search Users
- Create Posts with Images
- Home Feed
- Following Feed
- Like and Unlike Posts
- Add and Delete Comments
- Post Details
- Delete Posts
- Notifications
- Unread Notifications Counter
- Responsive CSS Design

## Technologies

- Python
- Django
- SQLite
- HTML5
- CSS3
- Pillow
